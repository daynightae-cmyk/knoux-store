## Performance

The WordPress library can expose huge catalogues but must never load them all at once.

Keep:
- server-side fetch
- cache/revalidate
- bounded page size
- pagination/search
- lazy images
- request dedupe
- graceful upstream failure

Do not preload thousands of WordPress.org items for visual spectacle.

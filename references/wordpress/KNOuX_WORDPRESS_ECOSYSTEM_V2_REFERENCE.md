# KNOuX WordPress Ecosystem V2 — Specialist References

Scope: /wordpress ecosystem landing and its WordPress discovery experience.
This is NOT global design authority and must not override the protected Home identity.

## Verified external references

### Vesper Cinematic — visual / motion authority
Source:
https://www.framer.com/marketplace/templates/vesper-cinematic/

Verified characteristics:
- dark editorial aesthetic
- immersive 3D moments
- cinematic scroll-driven motion
- selected work / case studies
- responsive desktop / tablet / mobile
- CMS-oriented project structure

KNOuX use:
Take composition confidence, negative space, cinematic section choreography, and premium dark editorial pacing.
Do not copy branding, copy, fonts, assets, or exact layouts.

### HosterFrame — domain / hosting information architecture
Source:
https://www.framer.com/marketplace/templates/hosterframe/

Verified characteristics:
- hosting-company structure
- home domain search
- domains page
- hosting-plan pages
- optional WHMCS integration
- live products/domains/pricing possible through its integration

KNOuX use:
Take the domain-search and hosting-service UX grammar.
Do not copy its visual identity.
Do not claim live availability/pricing unless KNOuX has a configured provider.

### Orbis — commerce / product presentation reference
Source:
https://www.framer.com/marketplace/templates/orbis/

Verified characteristics:
- motion-driven ecommerce
- immersive animations
- interactive 3D
- conversion-oriented product experience

KNOuX use:
Take premium item presentation and selection choreography for WordPress library entries.
Do not reproduce the commercial template itself.

### LuneFlow — library / CMS architecture reference
Source:
https://webflow.com/templates/html/luneflow-marketing-website-template

Verified characteristics:
- 20+ responsive pages
- CMS collections
- full ecommerce integration
- modular sections
- search/results-oriented architecture

KNOuX use:
Take modular library information architecture and scalable catalogue organization.
Do not copy Webflow implementation or design assets.

## Combined design decision

The new /wordpress experience should be:

VESPER
for atmosphere and motion

+
HOSTERFRAME
for domain / hosting UX

+
ORBIS / LUNEFLOW
for marketplace/library browsing

+
existing KNOuX truth and WordPress.org integrations
for all actual data.

The result must look native to KNOuX, not like four templates stitched together.

## System and motion

Matte black, graphite, ivory, platinum and restrained violet remain the material vocabulary. Three shared motion durations support interaction, reveal and cinematic change. Reduced motion disables nonessential transitions and renders the canonical mark statically. Functional operating states remain textual and do not rely on particle color.

The Build mark keeps its original particle pool mounted across routes. Its bounded aperture responds to the real engineering stage; it does not invent execution or provider verification. Blocked states settle, planning states respond, and completed artifacts remain readable. The context rail explicitly separates logical engine availability, provider configuration and project runtime.

The React review found no backend fetch waterfall or new secret transport: added interactivity is local visual state, native details, a cleaned-up IntersectionObserver, and existing provider state refs. Event listeners and observers are removed on unmount. Public product links remain available without the interactive runtime.

## Validation scope

The implementation passed lint, TypeScript, production compilation and the 731-test unit/integration suite during iteration. Browser repairs separately verified route geometry, compact navigation, plan sections and registry activation. Final exact-head local and GitHub results must be read from their actual execution evidence rather than inferred from these intermediate successes.

Security, provider adapters, OAuth lifecycle, Growth repositories, RLS, credential storage, WordPress safety, domain operations and origin boundaries were not changed. No environment secrets were read, copied into this worktree, output or committed. Existing authenticated runtime and third-party consent requirements remain real limitations, not visual fixtures.

This PR is for visual acceptance. It is not automatically merged or promoted by this evidence document.
